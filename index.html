Linux guide

Install Tor on Debian / Ubuntu

This basic example uses the distribution's package manager. Package versions and service names may vary. For current recommendations, consult the official Tor support documentation.

  1. Open a terminal on your own Debian or Ubuntu machine or server.
  2. Update package information and install Tor:
bash · install
sudo apt update
sudo apt install tor

On systems using systemd, check whether the service is available and running:

bash · status
systemctl status tor
⚠
Use a suitable environmentThese commands are for a Linux system where you have permission to administer packages. GitHub Pages and a normal browser tab cannot run these commands. Avoid running scripts from repositories you have not reviewed.
Access guide

Access legitimate onion services

Onion services use addresses ending in .onion and are accessed through the Tor network. For ordinary browsing and onion services on Android, use the official Tor Browser rather than an unknown third-party “dark web browser”.

  1. Download Tor Browser from the official Tor Project download page.
  2. Open it and connect to the Tor network.
  3. Get an onion address from the organisation's genuine HTTPS website or its verified documentation.
  4. Enter the exact address in Tor Browser. Do not trust a link merely because it appears in a directory or repository.

Tor is not simply a VPN. It can improve privacy, but it does not make every website, file, or user action anonymous or safe.

Trust checks

Verify an onion address

  • Confirm the source: look for the address on the organisation's official website or authenticated announcements.
  • Check every character: modern version 3 onion addresses use a long address of 56 characters before .onion.
  • Watch for impersonation: lookalike names, urgent payment demands, and unexpected downloads are warning signs.
  • Never share secrets: do not enter account passwords, recovery phrases, or payment details into an unverified site.
  • Keep software updated: use the official browser source and install security updates.

For technical details, read the Tor Project's onion services documentation.

Security notes

Never publish credentialsDo not commit passwords, API keys, access tokens, private keys, VPN profiles containing secrets, or server .env files. If a secret was exposed, revoke or rotate it immediately; deleting the file may not remove it from Git history.
  • Review shell scripts before running them; understand each command.
  • Use least-privilege permissions and keep the operating system updated.
  • Do not run untrusted GitHub Actions code on a self-hosted runner, especially for a public repository.
  • Use HTTPS for the published documentation and verify external links before entering sensitive information.
  • Remember: GitHub Pages hosts static files. It cannot run a persistent Tor daemon or host an onion service by itself.
Common questions

FAQ

Is Tor free?

Tor Browser and the Tor network are free to use. Running your own server may involve hosting or data costs.

Is Tor the same as a VPN?

No. They use different approaches to routing and privacy. Neither guarantees complete anonymity or protection from malicious downloads.

Does this GitHub Pages website open onion sites?

No. It is a static documentation page. Use Tor Browser to access onion services.

Can I create an onion service on GitHub Pages?

Not directly. A real onion service needs a host where Tor can run and be configured. GitHub Pages does not run background daemons.

Where can I learn more?

Start with the Tor Project, its support documentation, and the GitHub Pages documentation.
